# 오늘의 대구 · 실시간 날씨 및 예보 현황판

대구 중구 기준 좌표의 현재 기온과 24시간·7일 예보를 보여 주는 과제 4 정보판입니다. 사용자가 서울 기본안 대신 **대구 실시간 날씨 및 예보**를 선택했습니다. 매일 비교하는 주된 값은 지상 2m 현재 기온(°C)입니다.

현재 날씨는 Open-Meteo의 15분 간격 기상 모델 자료에 기반하며 관측소 실측값과 다를 수 있습니다. 화면에서 원천 기준 시각과 실제 조회 시각을 구분합니다. 예보는 미래 예상이며 실제 일별 관찰 건수에 넣지 않습니다. 비밀 API 키와 개인 위치 정보는 사용하지 않습니다.

[공개 정보판](https://skt-aleph-project-4-dashboard.vercel.app) · [제출 준비 상태와 소스 URL](docs/SUBMISSION.md)

## 실행

Node.js 22 이상에서 실행합니다.

```sh
npm start
npm test
npm run build
npm run collect
```

- `npm start`: `http://localhost:8004`에서 엽니다.
- `npm test`: 실제 데이터 처리와 공식 합성 재생을 검사합니다.
- `npm run build`: 수정 원본 `public/`을 배포 산출물 `dist/`로 복사합니다.
- `npm run collect`: 실행 시점의 실제 대구 공개 원천을 조회하고 응답 원문·SHA-256·일별 기록을 보관합니다. 수집 후 빌드·배포해야 공개 화면에 반영됩니다.

[일일 수집 작업](.github/workflows/daily.yml)은 매일 **09:20 KST 예정**입니다. 실행은 지연될 수 있으며 실제 수신 시각으로 날짜를 정합니다. 예약 설정 자체를 다음 날 수집 성공으로 간주하지 않습니다.

## 화면에서 확인할 것

1. `현재 값 새로 확인`을 누르고 현재 기온·단위·출처·원천 시각·조회 시각·Asia/Seoul을 확인합니다. 습도·체감온도·강수량·바람과 예보는 보조 정보입니다.
2. `데이터가 안 온다면?`에서 `5종 전체 검사` 후 `다시 시도 · D2 복구`를 누릅니다. 공식 합성 정상값 100→105, 실패 후 105 보존·stale, 복구 후 120·fresh/none·두 행을 확인합니다.
3. `하루에 한 줄`과 `실제 이틀, 원자료와 나란히`에서 날짜별 값과 원자료·저장값·화면값을 대조합니다. 둘째 실제 날짜가 없으면 변화값을 만들지 않습니다.

같은 KST 날짜의 일별 행은 **가장 최근 정상 수집값으로 갱신**하며 행 수는 하나입니다. 다음 날짜의 정상 수집은 새 행을 만듭니다. 전날 대비는 달력상 어제와 오늘의 저장값 차이이며 하루 평균이나 최고 기온의 차이가 아닙니다.

실제 심사용 두 날짜 자료는 `public/data/review-evidence.json`에 별도 보존합니다. 방문자 브라우저 기록·공식 합성 재생·서울 시제품 기록은 대구의 실제 두 날짜 증거에 합산하지 않습니다.

## 과제 상태

- 사용자 제공 5단계와 공식 정본 **T04-C01~C35, 35개 기준**을 문서에 연결했습니다.
- 공식 꾸러미의 manifest 대상 **17개 파일**과 **9개 fixture의 canonical SHA-256**을 대조했습니다. [검사 근거](docs/verification/asset-checks.json)
- 자동 검사 **32건**, 로컬 브라우저 검사 **27건**이 통과했습니다. 첫 실제 대구 기록은 **2026-09-22 09:36:25.628 KST, 21.9°C**이며 원천 기준 시각은 09:30 KST입니다. 현재 실제 날짜는 **1일/2일**입니다.
- 대구 변경분의 통합 검사·실제 수집·공개 접근 결과는 [검사 기록](docs/QA.md)에 따로 관리합니다. 서울 시제품의 검사 결과를 이번 변경의 통과 근거로 사용하지 않습니다.
- 실제 두 KST 날짜의 보존값과 변화값, 플랫폼의 `t04_day` 봉인 영수증 정확히 2건 대조가 완료되어야 C22~C24를 확정할 수 있습니다. 앱의 로컬 자료는 플랫폼 영수증을 대신하지 않습니다.

플랫폼에는 결과물 주소·전체 커밋 소스 주소·확인 4줄·판단 3줄만 제출합니다. 별도 인증 파일이나 증거 ZIP을 수작업으로 만들 필요는 없습니다. 기다린 시간은 6~7시간 작업시간에 포함하지 않습니다.
