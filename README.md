# 오늘의 대구 · 날씨와 예보

기상청 현재 날씨·예보·특보와 에어코리아 대기질을 간결하게 보여 줍니다. 기상 영상·생활 날씨·관측 기록·대구공항은 상단 메뉴로 나누고, 과제용 합성 실패 재생·일별 기록·원자료 대조는 별도 공개 검증 화면으로 분리했습니다.

[날씨 서비스](https://skt-aleph-project-4-dashboard.vercel.app) · [기록·검증](https://skt-aleph-project-4-dashboard.vercel.app/review.html) · [제출 문안](docs/SUBMISSION.md)

공공데이터포털 기상청·에어코리아 API를 서버에서 호출합니다. 현재·단기는 중구 격자(89,90), 중기는 권역/도시, 관측은 대구 ASOS 143, 공항은 RKTN 기준입니다. 레이더·위성·낙뢰·24시간 예상 일기도, 자외선·대기정체·잡초류 꽃가루, 영향·태풍 발표, 전날 관측, 공항 관측·이륙예보를 제공합니다. 실패하면 마지막 수신값과 이전 값 표시를 유지합니다. TAF·공항 해설은 대구 자료가 없는 응답을 확인했고 자료 없음으로 안내합니다. 읍면동 선택은 아직 미구현입니다. [확장 범위와 실제 검증](docs/EXTENDED-SERVICES.md).

## 실행

Node.js 22 이상에서 `npm start`, `npm test`, `npm run build`를 실행합니다. 로컬 주소는 http://localhost:8004 입니다. `public/`이 화면 원본이고 `dist/`가 정적 배포 산출물입니다. `api/weather.js`와 `lib/public-weather.mjs`가 서버 호출을 담당합니다. Vercel Production에는 `DATA_GO_KR_SERVICE_KEY`를 비밀 환경변수로 등록합니다. 로컬 시험은 Git 제외 파일 `.env.kma.local`의 같은 이름에 Decoding 키를 넣으면 `npm start`가 읽습니다. 키를 입력한 파일을 커밋하거나 공유하지 않습니다. 실제 수집은 `npm run collect`이며 날짜를 임의 지정하지 않습니다.

## 기록과 검사

- 메인의 전체 날씨 캐시와 검증 화면의 일별 저장을 분리했습니다. 실패한 새 응답으로 마지막 정상값을 덮어쓰지 않습니다.
- 실제 보관 자료는 9월 22일 21.9°C, 9월 23일 25.8°C의 두 건이며 변화는 +3.9°C입니다. 각 날짜의 첫 보관값 비교이며 같은 시각·일평균 비교가 아닙니다.
- 공개 일별 최근값은 25.5°C와 25.8°C로 +0.3°C입니다. 최근값 갱신 표와 심사용 첫 보관값은 별개이며 화면에 구분했습니다.
- 확장 후 자동 검사 51개, 새 화면 합성 검사 PC/모바일 각각 17개가 통과했습니다. 기본 화면의 이전 검사와 구분해 [확장 검사](docs/EXTENDED-SERVICES.md)와 [기본 연동 검사](docs/PORTAL-INTEGRATION.md)에 기록합니다.
- 이전 Open-Meteo 메인 배포에서 자동 검사 32개, 로컬 메인 12개·검증 화면 27개·원자료 4개가 통과했습니다. 공개 화면에서도 같은 43개가 통과했습니다.
- 이전 배포에서 메인·검증 화면과 전체 커밋 소스의 무인증 접근, 배포 파일 13개 SHA-256 일치를 확인했습니다.
- 플랫폼의 `t04_day` 봉인 영수증과 실제 제출 여부는 미확인입니다. 앱의 두 날짜 자료로 플랫폼 확인을 대신하지 않습니다.

일일 수집은 매일 09:20 KST로 예약되어 있지만 실행이 지연될 수 있습니다. 실제 수신 시각으로 날짜를 정합니다. 원천·지역이 바뀌는 향후 기상청 기록은 기존 Open-Meteo 기록과 섞지 않습니다.
