# 오늘의 대구 · 날씨와 예보

현재 날씨와 앞으로 24시간·7일 예보를 간결하게 보여 줍니다. 메인은 일상적인 날씨 확인에 집중하고 과제용 합성 실패 재생·일별 기록·원자료 대조는 별도 공개 검증 화면으로 분리했습니다.

[날씨 서비스](https://skt-aleph-project-4-dashboard.vercel.app) · [기록·검증](https://skt-aleph-project-4-dashboard.vercel.app/review.html) · [제출 문안](docs/SUBMISSION.md)

현재 데이터는 Open-Meteo의 대구 중구 기준 좌표 기상 모델 자료이며 실측 관측소 값과 다를 수 있습니다. 기상청 공공데이터 API는 [선정안](docs/PUBLIC-API-PLAN.md)에 정리했으며 아직 연결하지 않았습니다. API 키와 개인 위치를 브라우저에 넣지 않습니다.

## 실행

Node.js 22 이상에서 `npm start`, `npm test`, `npm run build`를 실행합니다. 로컬 주소는 http://localhost:8004 입니다. `public/`이 원본이고 `dist/`가 배포 산출물입니다. 실제 수집은 `npm run collect`이며 날짜를 임의 지정하지 않습니다.

## 기록과 검사

- 메인의 전체 날씨 캐시와 검증 화면의 일별 저장을 분리했습니다. 실패한 새 응답으로 마지막 정상값을 덮어쓰지 않습니다.
- 실제 보관 자료는 9월 22일 21.9°C, 9월 23일 25.8°C의 두 건이며 변화는 +3.9°C입니다. 각 날짜의 첫 보관값 비교이며 같은 시각·일평균 비교가 아닙니다.
- 공개 일별 최근값은 25.5°C와 25.8°C로 +0.3°C입니다. 최근값 갱신 표와 심사용 첫 보관값은 별개이며 화면에 구분했습니다.
- 자동 검사 32개, 로컬 메인 12개·검증 화면 27개·원자료 4개가 통과했습니다. 공개 화면에서도 같은 43개가 통과했습니다.
- 메인·검증 화면과 전체 커밋 소스의 무인증 접근, 배포 파일 13개 SHA-256 일치를 확인했습니다.
- 플랫폼의 `t04_day` 봉인 영수증과 실제 제출 여부는 미확인입니다. 앱의 두 날짜 자료로 플랫폼 확인을 대신하지 않습니다.

일일 수집은 매일 09:20 KST로 예약되어 있지만 실행이 지연될 수 있습니다. 실제 수신 시각으로 날짜를 정합니다. 원천·지역이 바뀌는 향후 기상청 기록은 기존 Open-Meteo 기록과 섞지 않습니다.
