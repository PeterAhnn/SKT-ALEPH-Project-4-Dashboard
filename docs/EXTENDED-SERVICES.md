# 기상 영상·생활 날씨·관측·대구공항 확장

2026-09-23. 로그인된 신청 목록의 4개 페이지를 확인했다. 당시 총 33개 중 이용 가능한 29개(날씨·환경 28개, 서울 버스 1개), 중지 4개였다. 이후 사용자가 국내 공항 이륙예보와 IWXXM 등 항공기상 서비스 4개를 추가했다고 알렸다. 계정 식별자·신청번호·키·로그인 화면은 보관하지 않는다.

## 실제 서비스 구성

메인의 현재 날씨·단기·중기·대기질·특보를 유지하고, 상단 메뉴에서 필요한 화면만 조회한다. `explore.html`은 과제 검사 기능을 노출하지 않는다. 과제 공식 합성 재생과 실제 이틀 자료는 기존 `review.html`에 보존한다.

## 확인된 데이터와 한계

- 실제 기상 영상 4종을 원본 이미지까지 열어 확인했다. 낙뢰는 요청한 분 수로 집계 기간을 단정하지 않는다. 일기도 `code=24`는 24시간 예상도로 표시한다.
- 생활지수 단계는 제공기관 설명서와 대조했다. 자외선 0–2/3–5/6–7/8–10/11 이상, 대기정체 25/50/75/100, 꽃가루 0/1/2/3은 서로 다른 척도다. 꽃가루는 잡초류 8–10월 제공 자료이며 참나무·소나무를 합산하지 않는다.
- 대구공항 현재 관측과 이륙예보는 실제 성공 응답을 확인했다. 이륙예보는 항공편의 출발시간·지연·결항 정보가 아니다. 원천 UTC를 KST로, 기압 0.01inHg를 inHg로 정규화한다.
- TAF `icao=RKTN`과 공항 해설 `airPortCd=RKTN` 조회는 대구 자료가 없는 응답이었다. ‘제공하지 않는 공항’이라고 단정하지 않으며, 조회 범위에 자료가 없다고 표시한다. 타 공항 자료를 대신 표시하지 않는다. 공항 해설의 공개 설명서에는 세부 공항코드 표가 없어 이 결과를 제공 범위 확정 근거로 쓰지 않는다.
- 영향예보는 확인 시 조회일 대구 자료가 없었다. ‘위험 없음’으로 해석하지 않는다. 향후 자료가 있을 때 분야 코드는 원문 코드로 표시하며 임의의 분야명을 붙이지 않는다.
- ASOS는 전날 기록이다. 시간별 수신값의 최저·최고는 공식 일 최저·최고와 다를 수 있다. 현재 기온이나 과제의 실제 두 날짜 조회 기록을 대신하지 않는다.

## 이번에 넣지 않은 신청 API

- [항공기상전문 IWXXM 2.0](https://www.data.go.kr/data/15059455/openapi.do): METAR/TAF 등을 국제 교환모델로 변환한 형식이다. 이미 수신 중인 항공기상전문과 중복하여 화면이나 호출을 늘리지 않았다.
- [CCTV 도로날씨](https://www.data.go.kr/data/15057966/openapi.do): 공식 2024-12-20 설명서의 CCTV·노드링크 목록에서 대구 지점을 확인하지 못했다. 수도권·영동 지점을 대구 도로처럼 표시하지 않는다. 이것은 API 전체의 최신 대구 지원 불가를 확정한 결론은 아니다.
- 레이더 관측 원자료, 레이더/위성 경량화 원자료 및 산출물: 원본 관측을 분석하는 자료이며, 일상적인 확인에는 공개 영상 4종을 먼저 사용한다.
- 방재기상 연보·월보, 지상기상월보·ASOS 일자료: 과거 통계 확장이므로 전날 ASOS 시간 관측과 중복하여 넣지 않았다.
- 서리 예측, 단기 통보문, 예보구역 조회: 현재 범위에서는 보류했다. 읍면동 선택도 아직 미구현이다. 메인의 중구 대표 격자를 동별 관측으로 표현하지 않는다.
- 서울 노선정보 및 중지된 버스/코로나 서비스: 대구 날씨 서비스 목적과 무관하다.
- 실제 항공편 출도착 API는 확인 당시 신청 목록에 없었다. [한국공항공사 실시간 운항정보](https://www.data.go.kr/data/15158625/openapi.do) 호출도 인증 거절이었다. 공개 화면에는 가짜 운항표를 넣지 않았으며 서버 허용 목록에서도 제외했다.
- 별도 인증키가 필요한 기상청 API허브는 사용하지 않는다.

## 실패·비밀값 보호

기존 5개와 새 14개 조회 종류만 서버에서 허용한다. API URL·지역·인증키를 사용자 입력으로 받는 범용 프록시는 없다. 키는 Vercel Production 환경변수에서만 읽는다. 브라우저는 같은 사이트의 `/api/weather?kind=...`만 호출한다. 영상은 인증 없는 기상청 HTTPS 이미지다. 이미지 호스트·확장자 허용 목록을 검사하며 사용자정보·포트·쿼리·프래그먼트가 있는 URL은 거절한다.

메뉴별 지연 조회, 항목별 캐시와 중복 호출 통합을 적용했다. 각 항목이 독립적으로 실패·이전 수신값·개별 다시 시도를 표시한다. 새 응답에 자료가 없어도 기존 정상값을 덮어쓰지 않는다. 브라우저를 다시 열면 저장값을 이전 수신값으로 표시한 뒤 새 조회로 확인한다. 서버 메모리 캐시는 영구 저장소가 아니다.

- 새 화면 합성 검사 PC/모바일 각각 17/17. 메뉴별 호출, 부분 실패, 실패 5종, 값 보존, 빈 응답 후 보존, 복구, 원문 문자 처리, 화면폭, 기존 과제 기록 불변을 확인했다.
