## 제출 입력란과 별도로 보관하는 확인 사항

- 2026-09-28 공개 검증 화면 27/27, 실제 원자료 무결성 검사 4/4, 자동 검사 65/65 통과. 공식 자산 17개 SHA-256 일치. 검증용 새 격리 브라우저에서 결과물·전체 커밋 소스 접근 확인.
- 현재 날씨 서비스는 기상청·API허브·에어코리아, 과제의 고정 실제 이틀 보관 자료는 Open-Meteo이다. 서로 다른 원천을 변화 계산에 섞지 않는다.
- 앱의 두 날짜·값·원자료·변화는 확인했다. ALEPH T04의 선택 과정 기록은 2026-09-28 실제 24.7°C로 첫날 1개를 등록했다. 둘째 실제 날짜가 남아 있다. 플랫폼은 기록 없이도 제출·승인이 가능하다고 명시하나, 공식 계약의 C22~C24 플랫폼 서버 날짜 증거까지 충족한 것은 아니다. 자세한 구분은 FINAL-REPORT.md를 따른다.
- 앱의 고정 심사용 두 건과 계속 쌓이는 일별 최근값 기록은 별도이다. +3.9°C는 고정 두 자료의 차이이며 오늘과 어제의 현재 기온 차이가 아니다.
- 실제 플랫폼 제출·강사 승인·최종 채점은 수행하지 않았다. 보고서는 보관용이며 과제 안내의 플랫폼 제출물은 URL·확인 4줄·판단 3줄이다.
