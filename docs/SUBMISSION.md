## 재현·통과 확인 4가지 — 검증 후 확정할 초안

```text
어디로 가나요: https://skt-aleph-project-4-dashboard.vercel.app 의 현재 기온, 공개 관찰 기록, 데이터가 안 온다면? 영역으로 갑니다.
무엇을 하나요(3단계 이내): 1) 현재 값 새로 확인 2) 5종 한 번에 확인 3) 공개 관찰 기록에서 어제·오늘 값과 전날 대비 확인
무엇이 보이면 통과: 실제 원천·단위·시각이 보이고, 실패 5종에서 정상값과 기록이 보존되며, 서로 다른 실제 KST 날짜 2건과 정확한 변화값이 확인됩니다.
안 될 때: 조회 실패 이유와 마지막 정상 수신 시각을 확인하고 다시 시도합니다. 정상값·어제 기록이 없으면 빈 상태·비교 불가 안내가 보이며, 공식 검사 대조와 실제 날짜 기록이 미완료이면 완주로 판단하지 않습니다.
```
