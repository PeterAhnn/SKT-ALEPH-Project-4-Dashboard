## 재현·통과 확인 4가지

```text
어디로 가나요: https://skt-aleph-project-4-dashboard.vercel.app 에서 날씨를 보고 하단 ‘기록·검증’으로 이동합니다.
무엇을 하나요(3단계 이내): 1) 새로고침 후 현재 값·출처·두 시각 확인 2) 기록·검증에서 실패 버튼과 다시 시도 · D2 복구 선택 3) 실제 이틀의 원자료·저장값·화면값과 변화 대조
무엇이 보이면 통과: 대구 기온·°C·출처·원천/조회 시각·KST가 보이고 실패마다 합성 정상값 105·오래된 값이 유지됩니다. D2 복구는 120·fresh/none·두 행이며, 실제 9월 22일 21.9°C와 23일 25.8°C의 보관값·원자료·화면값 및 +3.9°C 변화가 일치합니다.
안 될 때: 실패 원인과 다시 시도를 표시하며 마지막 정상값을 보존합니다. 예보가 없으면 해당 예보만 자료 없음으로 표시하고 실제 자료의 해시·날짜 대조가 실패하면 확인 필요와 비교 불가를 표시합니다.
```

