# 과제 4 · 오늘의 진짜 정보판 — 데이터가 안 올 때

## 사용자가 제공한 과제 내용

계획시간 6~7h · 실제 날짜 2일

날씨·환율·교통·게임 상태처럼 실제로 변하는 값 하나를 매일 기록하고, 어제와 비교하며, 데이터가 오지 않을 때도 정직하게 설명하는 정보판을 만듭니다. 별도 경과 기간: 서로 다른 실제 날짜의 기록 2건. 기다린 시간은 6~7시간 작업시간에 포함하지 않습니다.

### 왜 이걸 하는가

진짜 데이터 제품은 값이 잘 올 때보다 늦거나 틀릴 때 신뢰가 갈립니다. 마지막 정상값을 보존하면서 현재 상태를 정직하게 설명하는 법을 익힙니다.

### 제출물

- 결과물 주소 — 무로그인 공개 심사 화면
- 소스 주소
- 짧은 확인 방법 4줄 — 위치 / 3단계 이내 행동 / 통과 모습 / 안 될 때 모습
- AI와 나의 판단 3줄 — AI에게 맡긴 일 / 직접 판단한 일 / AI 제안을 따르지 않은 일(없으면 이유)

### 완주 체크리스트

- 실제 공개 원천의 값과 맥락이 보입니다.
- 외부 실패 다섯 종류를 합성 재생합니다.
- 마지막 정상값과 일별 기록을 보존합니다.
- 서로 다른 KST 날짜의 실제 기록 2건과 변화값을 대조합니다.
- 개인정보·비밀값 없이 확인법을 제출합니다.

### 증거 보관 기준

플랫폼에는 주소·소스·짧은 확인법·AI와 본인 판단만 냅니다. 날짜·해시·과제 버전은 플랫폼이 기록합니다.

## 현재 구현의 선택과 범위

| 항목 | 현재 기본안 | 완료 판단에 필요한 것 |
| --- | --- | --- |
| 실제 값 | 서울 중구 기준 좌표의 Open-Meteo 모델 기반 현재 기온 | 실제 원천 조회와 값·맥락 확인 |
| 실패 재생 | 연결 실패·응답 지연·서버 오류·잘못된 데이터·오래된 데이터 | 자체 5종 검증 및 공식 꾸러미 대조 |
| 보존 | 공개 JSON과 방문자 로컬 저장을 분리 | 실패·새로고침·저장 오류 동작 확인 |
| 일별 기록 | 실제 KST 수집 날짜의 첫 정상값 | 서로 다른 실제 날짜 두 건 |
| 변화값 | 오늘 대표값 − 달력상 어제 대표값 | 양쪽 기록과 계산 결과 대조 |
| 공개 심사 | 정적 웹 화면과 전체 커밋 소스 URL | 새 시크릿 창에서 두 URL 접근 검사 |

서울 기온과 원천 선택은 진행을 위한 AI 기본안입니다. 사용자가 직접 결정했다고 기록하지 않습니다. 공식 상세 1~5단계 카드와 공식 합성 검사 꾸러미는 아직 제공받지 않았으므로, 현재 구현을 공식 세부 기준 충족으로 확정하지 않습니다.

공통 가이드에 따라 공식 합성 검사 꾸러미는 정상 흐름과 실패 5종을 재생하는 용도이며 실제 원천 조회·날짜 관찰을 대체하지 않습니다. 자체 검사도 실제 날짜 증거와 구분합니다.

## 제출 준비 원칙

제출 문안은 `docs/SUBMISSION.md`에서 관리합니다. 결과물은 공개 HTTPS, 소스는 실제 확인한 전체 커밋 해시의 `/commit/` URL을 사용합니다. 확인 4줄과 판단 3줄은 각각 1,500자 이내로 작성합니다. 검사 자료는 별도 보관하며, 사용자 원문에 없는 보고서 첨부를 필수 제출물로 추가하지 않습니다.
