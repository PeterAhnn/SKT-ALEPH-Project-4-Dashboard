# 공공데이터포털 서버 연동 · 2026-09-23

메인 현황판은 Vercel 서버가 공공데이터포털 API를 호출한다. `DATA_GO_KR_SERVICE_KEY`는 Production의 비밀 환경변수이며 브라우저에 전달하지 않는다. 별도 기상청 API허브 인증키나 서비스를 사용하지 않는다.

## 반영 범위

- 기상청 초단기실황: 대구 중구 격자 89,90의 기온·습도·바람(m/s)·1시간 강수량. 강수 없음은 맑음과 다르므로 하늘 상태를 만들지 않는다.
- 단기예보: 발표 시각에 따른 시간별 기온·강수확률과 일별 최저·최고. 응답에 없는 오늘 최저·최고를 남은 시간의 최솟값으로 대체하지 않는다.
- 중기예보: 대구·경북 육상 날씨, 대구 도시 기온. 단기와 발표·공간 범위가 다르므로 별도 영역이다.
- 기상특보: 최신 전국 특보현황·예비특보 원문. 대구 포함 여부만 안내하며 미수신을 특보 없음으로 표시하지 않는다. 경보가 계속 유효할 수 있으므로 발표 시각과 마지막 조회 시각을 분리한다.
- 에어코리아: 수창동 우선, 응답의 실제 측정소·측정시각과 PM10·PM2.5 표시. 결측·점검은 0으로 바꾸지 않는다. 실제 성공 응답과 간헐적 시간초과 모두 관찰했다.

읍면동 선택과 레이더·영향예보·위성·낙뢰 영상은 **아직 미구현**이다. 신청 완료를 연동 완료로 기록하지 않는다. 선택 확장인 생활지수·꽃가루·CCTV 등도 이번 변경에 포함하지 않는다.

## 실패·키 보호

서버는 조회 항목 5개만 허용하고 요청자가 임의의 URL·위치·키를 전달할 수 없게 한다. 원천 URL 및 오류 전문을 응답·로그에 내보내지 않으며, 실제 비밀값과 인코딩된 비밀값이 응답에 포함되는지도 전송 전에 확인한다. 인증·호출제한·시간초과·연결·형식 오류를 구분한다.

메인은 서비스별 정상 응답을 독립적으로 보관한다. 실패 시 마지막 정상값을 유지하고 이전 수신값·다시 시도를 표시한다. Vercel 서울 리전을 사용하며 항목별 메모리 캐시와 CDN 캐시로 반복 호출을 줄인다. 서버 메모리 캐시는 영구 저장소가 아니며, 방문자 브라우저의 마지막 정상 캐시도 최초 방문에는 존재하지 않는다.

로컬 `.env.kma.local`은 `npm start`에서 읽지만 현재 비어 있다. 키는 Vercel에만 등록했으므로 로컬 실제 호출은 설정 대기 상태이며 합성 자료로 UI를 검사했다. 로컬 파일과 Vercel 환경변수는 자동 동기화되지 않는다.
