## 공식 재생에서 대조한 동작

- 초기화→D1-A(100)→D1-B(105): 같은 record ID·일별 한 행, 값만 최신 성공으로 갱신합니다.
- 지연·외부 원천 거절·호출 제한·오프라인·형식 변경: 다섯 오류 코드가 구분되고 105·기존 한 행을 유지합니다.
- 실패 상태: `stale` 및 오류별 다음 행동을 표시할 수 있는 상태를 반환합니다.
- timeout→RECOVER-D2: `fresh/none`, 값 120, 총 두 행·다음 날짜 신규 한 행으로 복구합니다.
- D1→D2: 저장한 105와 120의 변화 절대값은 15입니다.
- 합성 상태 초기화와 실제 대구 저장 영역은 분리됩니다. 합성 날짜로 실제 관찰을 채우지 않습니다.

위 상태 전이는 자동 검사와 로컬 브라우저에서 확인했습니다. 27개 로컬 검사에는 실제 원천·24시간/7일 예보·원자료/저장값/화면값 대조, 공식 실패별 서로 다른 안내와 반복 복구, 합성/실제 저장 분리, 실제 조회 경로에 오류를 주입한 보존 검사, 정상 원천 복구, 내보내기·테마·390px 화면 가로폭 확인이 포함됩니다. 공개 배포는 별도 확인이 필요합니다. 합성 실패가 실제 원천 장애 발생을 증명하는 것은 아닙니다.
