어디로 가나요: https://skt-aleph-project-4-dashboard.vercel.app 의 하단 ‘기록·검증’으로 이동합니다.
무엇을 하나요(3단계 이내): 1) 실제 조회에서 기온·단위·출처·두 시각·KST 확인 2) 공식 실패 5종과 ‘다시 시도 · D2 복구’ 재생 3) 실제 이틀 보관 자료의 원자료·저장값·화면값·변화 대조
무엇이 보이면 통과: 실패마다 합성 마지막 정상값 105와 오래된 값 표시가 유지되고 오류 설명이 달라집니다. D2 복구는 120·fresh/none·두 행입니다. 실제 보관 자료 9월 22일 21.9°C와 23일 25.8°C가 원자료와 일치하고 변화는 +3.9°C입니다.
안 될 때: 원인별 안내와 다시 시도가 나타나며 마지막 정상값을 보존합니다. 보조 자료가 없으면 빈 카드를 숨기고 수신 상태를 안내합니다. 실제 원자료의 해시·날짜가 맞지 않으면 ‘확인 필요’와 비교 불가를 표시합니다.

AI에게 맡긴 일: 공개 API 조사·서버 연동, 지역 선택·현재 위치·예보·기상소식 화면, 공식 실패 재생, 기록 보존·원자료 대조와 자동 검사·문서 작성.
내가 판단한 일: 대구 날씨를 주제로 정하고 실사용 중심 화면, 읍면동 선택, 빈 카드 숨김, 새 기상소식 팝업을 요청했다. 필요한 API를 신청하고 서버 인증키를 등록했다.
AI 말을 안 들은 일: 과제 검증 기능이 메인에 많이 드러난 구성을 그대로 쓰지 않고, 날씨 서비스와 공개 기록·검증 화면을 분리하도록 요청했다.
