# 지역 선택·기상 소식·API허브 확장 (2026-09-28)

사용자의 새 요청에 따라 API허브 사용 보류 결정을 변경했다. 기존 공공데이터포털 경로를 유지하면서 서버 전용 `KMA_APIHUB_KEY`를 사용한다. `DATA_GO_KR_SERVICE_KEY`와 서로 다른 키이며 어느 키도 브라우저에 전달하지 않는다. Vercel 세 환경에 두 변수의 등록을 확인했다. Secret 값은 로컬로 내려받을 수 없어 실제 수신은 검증용 배포에서 확인했다.

## 화면과 데이터 범위

- 공식 격자 목록의 대구 9개 구·군, 읍면동 150곳, 구·군 대표지점 9곳. 군위군 포함. 선택은 URL과 브라우저 저장에 유지하며 현재 실황·단기·초단기예보의 nx/ny를 변경한다. 허용 목록에 없는 ID와 중복 매개변수는 서버에서 거절한다.
- 다른 지역의 수신값과 서버/브라우저 캐시를 섞지 않는다. 동별 관측소 실측이 아니라 5km 격자의 대표 실황·예보임을 표시한다. 중기(대구 도시/대구·경북 권역), 대기질(표시된 측정소), 생활지수(대구), 종관관측(143), 공항(RKTN)은 고정 범위다.
- 6시간 초단기예보 추가. 실제 응답 발표시각이 요청 시각과 다를 수 있어 원천의 발표시각을 검증해 표시하며, 2시간을 넘긴 발표와 다른 격자는 거절한다.
- API허브의 종관 실시간 관측에서 기온·이슬점·습도·바람·해면기압·시정·지면온도·일조·일사를 수신 확인했다. 적설·누적 강수 등 결측값은 0으로 바꾸지 않는다. 관측 자외선은 생활지수 예보와 별도로 표시한다.
- 위성 가시(vi006), 수증기(wv069), 주야간합성(rgbdn)을 기존 적외(ir105)·레이더·낙뢰·일기도에 추가했다. 자외선관측·황사관측도 서버 허용 종류에 추가했다. 황사 관측은 정상 품질의 대구 값이 있을 때만 표시한다.
- 수신값 없는 보조 카드와 영상 로딩 실패 카드는 숨긴다. 부분 실패는 작은 공통 안내로 표시하고 새로고침으로 재시도한다. 마지막 정상값이 있으면 지우지 않고 이전 수신값으로 표시한다. 현재 날씨 전체가 실패한 경우에도 원인을 보여 준다.
- 기상특보·영향예보·태풍을 공통 기상 소식으로 모았다. 소식 배지·상단 고정 띠·새 발표 팝업·펼쳐진 원문·지난 발표 보관을 제공한다. 발표 내용의 변경을 식별하며 같은 발표는 반복 팝업을 띄우지 않는다. 대구/군위 언급 특보와 영향예보, 종료되지 않은 태풍 발표가 팝업 대상이다. 전국 특보 원문을 읍면동 특보로 단정하지 않는다.
- 기상 소식은 페이지가 열려 있을 때 5분 간격 및 다시 활성화할 때 조회한다. OS 푸시·문자 알림은 아니다. 보관은 해당 브라우저의 최근 60건이며 공식 특보 이력 전체가 아니다. 실패는 위험 없음/특보 없음으로 표시하지 않는다.

자동 검사 62건 통과. 새 메인/알림 합성 브라우저 검사 PC·모바일 각 12건, 빈 카드/보존 검사 각 6건 통과. 군위군을 실제 선택해 URL·제목·읍면동 목록 변경과 이전 중구 값이 나타나지 않음을 확인했다. 실제 검증용 배포에서 군위 실황, 대구공항 METAR, 새 위성 3종, 실시간 종관관측, 관측 자외선을 확인했다. `docs/verification/regional-live-preview.json`은 특정 조회 시점의 결과이며 미래 가용성을 보장하지 않는다.

과제 `review.html`의 실제 이틀 원자료와 공식 합성 fixture를 변경하지 않았다. 플랫폼 t04_day 영수증은 여전히 미확인이다. 이번 합성 UI 검사·실제 원천 수신을 플랫폼 영수증이나 학생의 직접 확인으로 기록하지 않는다.

2026-09-28 KST 공개 주소에 배포했다. 실제 26종 조회에서 22종은 값이 수신됐고 황사·영향예보·TAF·공항 해설 4종은 정상 빈 응답이었다. 빈 응답은 발행/관측 자료가 있을 때만 카드로 표시한다. 초단기예보 6행과 군위군 삼국유사면의 실제 예보를 확인했다. 기존 과제 검증 화면 회귀 검사 27건도 통과했다. 모바일 390px에서 지역 선택과 초단기예보의 가로 넘침이 없었고 새 태풍 발표의 실제 팝업·상단 소식 표시를 확인했다.

## 현재 위치 선택 (2026-09-28)
지역 선택의 현재 위치 버튼을 눌렀을 때만 브라우저 위치 권한을 요청한다. 좌표는 브라우저 메모리에서 공식 읍면동 대표 좌표와 비교하며 서버 전송·좌표 저장·공개 기록을 하지 않는다. 선택된 지역 ID만 기존 방식으로 저장한다. 가장 가까운 대구 읍면동 예보 지점이며 실제 행정 경계 판별은 아니다. 대표 지점에서 20km를 넘거나 위치 오차가 5km를 넘으면 자동 선택하지 않는다. 권한 거절·시간 초과·지원 불가·오차 과다에는 기존 선택을 유지하고 재시도/수동 선택 안내를 표시한다.

자동 검사 65건 통과. 합성 위치로 모바일 UI 9건 통과, 동인동 좌표로 동인동 URL·선택 변경 확인. 실제 개인 좌표는 수집하거나 검증 증거에 남기지 않았다.
